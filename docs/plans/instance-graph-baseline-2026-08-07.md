# Instance graph baseline — 2026-08-07

This pins the pre-`InstanceGraph` metadata baseline for steps 1–3 of
[`instance-graph-dimension-constraints.md`](instance-graph-dimension-constraints.md).
It is a local development-database measurement, intended as a comparison point
for the graph builder rather than a universal performance budget.

## Representative draft snapshot

`espoo`, measured by wrapping `build_instance_snapshot()` in
`CaptureQueriesContext` and serializing `model_dump(mode='json')` as compact
JSON:

| Nodes | Edges | Dataset ports | Queries | Build time | JSON size | Payload/datapoint queries |
|---:|---:|---:|---:|---:|---:|---:|
| 135 | 186 | 86 | 3 | 94.2 ms | 447,012 bytes | 0 |

The wall time is a single warm-process observation and should be remeasured as
a distribution when step 4 adds graph construction and caching. Query count,
serialized size, and the zero-payload-query invariant are the durable parts of
this baseline.

## Generated dimension-field inventory

The 55 existing parse-oracle snapshots contained 599 grouped multi-ports with
non-empty `required_dimensions == supported_dimensions`, and no non-empty
`supported_dimensions` value differing from `required_dimensions`. These are
generated by the multi-port grouping path, not evidence of an independently
authored upper-bound contract.
